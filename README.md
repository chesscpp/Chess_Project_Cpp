# Objectif
- Jeu d'échecs à 2 joueurs humains, 
- Règles classiques complètes avec une pendule par joueur
- Implémentatiob sur une interface graphique, 
- Bonus : ajout d'une IA 

# Organisation
Environ 10 h par personne, soit 20 h à deux.

# Outils
- Langage : C++
- Interface graphique : SFML3, intégration dans Cmake, adaptée pour la 2D

- Types de base
- Pièces
- Plateau
- Règles
- Horloge
- Partie
- Joueurs
- Interface SFML
